# Диагностика показателей магазина — HTML-дашборд

## Назначение

Автономное мини-приложение помогает владельцу или управляющему розничного магазина:

- рассчитать средний чек, конверсию, количество товаров в покупке, среднюю цену товара и ориентировочную валовую прибыль;
- сравнить два сопоставимых периода;
- определить одну главную слабую зону: трафик, конверсию, средний чек или прибыльность;
- увидеть один дополнительный риск, если существенно ухудшился ещё один показатель.

Диагностика является управленческой подсказкой. Она не заменяет проверку ассортимента, цен, наличия товара, источников трафика и условий работы магазина.

## Как открыть

1. Откройте папку `products/diagnostika-pokazateley-magazina/html-dashboard/`.
2. Для работы с исходной версией дважды щёлкните `index.html` или откройте файл через меню браузера.
3. Установка, регистрация, сервер и интернет не требуются.

Для передачи клиенту используйте единый файл `Диагностика_показателей_магазина.html`. В него уже встроены разметка, стили и JavaScript, поэтому он работает самостоятельно и не зависит от соседних файлов.

## Как пользоваться

1. Выберите режим «Текущее состояние» или «Сравнение периодов».
2. Введите все пять показателей. Наценка указывается в процентах к закупочной цене. Количество чеков, товаров и посетителей указывается только целыми положительными числами.
3. Для сравнения используйте периоды одинаковой длительности и со сходными условиями работы.
4. Нажмите «Провести диагностику».
5. Сначала прочитайте главную слабую зону и её смысл, затем изменения показателей.

Кнопка диагностики становится доступной только после корректного заполнения обязательных полей. Ошибки показываются непосредственно под соответствующим полем.

## Поддерживаемые браузеры

Актуальные версии Chrome, Edge, Firefox и Safari на компьютерах, планшетах и телефонах. Интерфейс рассчитан на ширину от 320 px. Для модального окна очистки требуется поддержка HTML-элемента `dialog`, доступная в актуальных версиях перечисленных браузеров.

## Хранение и очистка данных

Последние введённые значения сохраняются только в `localStorage` текущего браузера. Приложение не содержит сетевых запросов и не отправляет данные наружу.

Чтобы удалить сохранённые значения, нажмите «Очистить данные» и подтвердите действие в собственном модальном окне приложения. Очистка данных сайта в настройках браузера также удалит сохранённые значения.

## Автоматические тесты

Откройте `tests.html` в браузере. Страница автоматически выполняет 23 сценария и для каждого показывает название, ожидаемый результат, фактический результат и статус.

На момент обновления продукта: **пройдено 23 из 23 сценариев**. Для диагностических сценариев проверяются сразу название зоны, короткий факт, смысл вывода и дополнительный риск. Также отдельно проверяются системное снижение, стабильность, рост, граница 5%, ошибки ввода, нулевая выручка первого периода, десятичная запятая для денежных показателей, одновременное снижение выручки и прибыли, режим текущего состояния и запрет дробных значений для чеков, товаров и посетителей.

## Что пока не включено

- импорт данных из кассовой системы или Excel;
- история нескольких сравнений и облачная синхронизация;
- выгрузка отчёта в PDF;
- рекомендации по конкретным акциям, ассортименту или персоналу;
- серверная часть, регистрация, оплата и личный кабинет.

Фактическую мобильную проверку на физических устройствах нужно провести отдельно, если в рабочей среде нет браузера с инструментами адаптивного просмотра.
