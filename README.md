# business-automation

Автоматизация для текстиля, одежды розница и оптом:

- HTML-сайты (лендинги)
- SaleBot (воронки 8 экранов)
- CRM (Google Sheets + Make.com)
- Парсинг клиентов (2ГИС, ВК, Авито)
- AI-инструменты (ChatGPT, автоотчёты)
