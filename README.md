# business-automation

Репозиторий проекта «Розница в цифрах» — развивающейся бизнес-системы для розничной торговли.

Она объединяет сайт, экспертный контент, автономные цифровые продукты и HTML-инструменты. В дальнейшем система может включать приложения, электронные книги, курсы, лендинги, материалы социальных сетей, площадки дистрибуции, аналитические инструменты, автоматизацию, платежи, выдачу цифровых продуктов и другие производственные системы.

Основная бизнес-логика: **DISCOVERY → CONTENT → TRUST → PRODUCT → SALE → DELIVERY → REPEAT**.

## Что находится в репозитории

- `src/` и `public/` — публичный сайт и его контент.
- `products/` — автономные цифровые продукты.
- `paid-products/` — будущие продукты и спецификации.
- `docs/project-knowledge/` — знания о проекте, бренде, контенте и продуктовой системе.
- `docs/site/` — документация и источники истины сайта.
- `docs/ai/` — модельно-нейтральная AI-архитектура и протокол передачи задач.

Точная карта исходников, генерируемых каталогов и QA-артефактов находится в [`docs/ai/PROJECT_MAP.md`](docs/ai/PROJECT_MAP.md).
