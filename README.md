# business-automation

Репозиторий проекта `Докрути` — экспертно-продуктовой бизнес-системы Светланы Тарасовой.

Здесь находятся публичный сайт, контентные коллекции, сохранённые кодовые продуктовые артефакты и техническая AI-документация.

Устойчивый бизнес-контекст синхронизируется из актуальной базы Google Drive; текущее оперативное состояние живёт в Google Sheet `Бизнес-система`.

## Структура

- `src/`, `public/` — сайт Astro и публичные ассеты.
- `products/` — кодовые продуктовые артефакты; их текущий статус всегда сверяется с `Бизнес-системой` и product master.
- `docs/project-knowledge/` — синхронизированные устойчивые документы `Докрути`.
- `docs/site/` — только актуальная site-документация после site-freeze.
- `docs/ai/` — контракт, карта, capabilities и handoff-процесс.

Старые продуктовые спецификации, удалённые из рабочего дерева, остаются доступны в Git-истории и не считаются действующими только потому, что когда-то были созданы.

Любой AI-исполнитель начинает с [`AGENTS.md`](AGENTS.md), затем читает только необходимое по [`docs/ai/PROJECT_MAP.md`](docs/ai/PROJECT_MAP.md).
