# Техническое задание продукта «Конструктор прибыльных акций для магазина»

## 1. Краткий вывод

«Конструктор прибыльных акций для магазина» — платный MVP-продукт в формате Excel / Google Таблицы для владельцев небольших магазинов одежды, обуви, домашнего текстиля, товаров для дома и малых розничных сетей.

Главная задача продукта — помочь владельцу магазина быстро понять, какую акцию можно запускать без убытка, какую скидку можно дать, сколько нужно продать, как изменятся выручка и валовая прибыль, окупится ли акция и какая механика выгоднее.

Продукт должен быть простым. Пользователь не должен знать финансовый анализ. Он вводит базовые цифры: цену, себестоимость или наценку, текущие продажи, планируемую скидку, расходы на акцию и ожидаемый рост продаж. Таблица сама считает результат и даёт понятную рекомендацию: «можно запускать», «можно, но осторожно», «опасно», «запускать нельзя».

Важно: для малого бизнеса нормальная рабочая наценка чаще находится примерно в диапазоне 70–100%, иногда до 120%. В продукте нельзя подавать наценку 150% как норму. Если пользователь вводит завышенную наценку, таблица должна не запрещать расчёт, но показывать предупреждение.

## 2. Цель продукта

Цель MVP — дать владельцу магазина простой инструмент для расчёта акций до запуска, чтобы снизить риск потери прибыли.

Продукт помогает ответить на вопросы:

- какую акцию выбрать;
- какую скидку можно дать без убытка;
- сколько единиц товара нужно продать;
- какой рост продаж нужен для сохранения прибыли;
- как изменится выручка;
- как изменится валовая прибыль;
- окупятся ли расходы на акцию;
- какая из нескольких акций выгоднее;
- какие риски нужно проверить до запуска.

## 3. Целевая аудитория

Основные пользователи:

- владельцы магазинов одежды;
- владельцы магазинов обуви;
- владельцы магазинов домашнего текстиля;
- владельцы магазинов товаров для дома;
- управляющие небольших розничных сетей;
- предприниматели, которые сами считают акции и не имеют финансового директора.

Уровень подготовки пользователя:

- умеет работать с Excel или Google Таблицами на базовом уровне;
- знает розничную цену товара;
- примерно знает закупочную цену или наценку;
- может оценить текущие продажи;
- не обязан понимать маржинальность, валовую прибыль, точку безубыточности и ROI.

## 4. Формат MVP

Формат:

- Google Таблица;
- Excel-файл с тем же составом листов;
- русский язык интерфейса;
- без HTML;
- без Telegram-бота;
- без сложной автоматизации;
- без макросов на первом этапе.

Принцип MVP:

- пользователь вводит данные только в выделенные поля;
- все расчёты выполняются автоматически;
- таблица показывает подсказки, ошибки и итоговую рекомендацию;
- таблица содержит библиотеку из 50 механик акций.

## 5. Стиль и оформление

Оформление должно соответствовать Brand System проекта.

Цвета:

- белый фон;
- графитовый текст;
- тёмно-синие заголовки;
- оливковый / хаки для акцентов;
- красный только для критичных предупреждений;
- жёлтый / светло-оранжевый для зоны риска;
- зелёный для безопасных решений.

Шрифты:

- Inter для основного текста и таблиц;
- Montserrat SemiBold для заголовков, если технически доступно;
- если в Google Таблицах шрифт недоступен, использовать Arial или стандартный sans-serif.

Тон подсказок:

- простой;
- спокойный;
- без давления;
- без обещаний быстрых денег;
- с объяснением «что это значит для магазина».

## 8. Лист `00_Инструкция`

Назначение: быстро объяснить владельцу магазина порядок работы.

Содержание листа:

1. Что делает таблица.
2. Какие данные нужно подготовить.
3. Как выбрать механику акции.
4. Как заполнить товарные данные.
5. Как прочитать результат.
6. Что означает цветовая индикация.
7. Что делать, если таблица показывает предупреждение.
8. Важное ограничение: таблица помогает принять решение, но не гарантирует продажи.

Ключевые блоки:

- «Заполните только жёлтые поля».
- «Не меняйте серые поля — там формулы».
- «Зелёный результат — можно рассмотреть запуск».
- «Жёлтый результат — проверьте риски».
- «Красный результат — акция может съесть прибыль».

## 9. Лист `01_Настройки`

Назначение: задать общие параметры магазина и пороги оценки.

### Данные, которые вводит пользователь

| Поле | Описание | Пример |
|---|---|---|
| Тип магазина | Одежда, обувь, текстиль, товары для дома, смешанный формат | Одежда |
| Валюта | Основная валюта расчётов | руб. |
| НДС учитывать | Да / Нет | Нет |
| Средняя целевая наценка, % | Нормальный ориентир магазина | 80% |
| Минимально допустимая валовая маржа, % | Ниже этого уровня акция опасна | 25% |
| Минимально допустимая прибыль после акции, % от базы | Например, не ниже 90% от прибыли до акции | 90% |
| Максимально допустимая скидка по умолчанию | Ограничитель для быстрых расчётов | 30% |
| Допустимый бюджет акции | Реклама, оформление, бонусы продавцам | 5 000 руб. |
| Период расчёта | День, неделя, месяц | Неделя |

### Автоматические настройки

Таблица автоматически задаёт зоны оценки:

- зелёная зона: прибыль после акции не ниже 100% от базовой прибыли;
- жёлтая зона: прибыль после акции от 90% до 99% от базовой прибыли;
- красная зона: прибыль после акции ниже 90% от базовой прибыли или отрицательная.

Порог 90% можно менять в настройках.

## 10. Лист `02_Ввод_товара`

Назначение: собрать исходные данные по товару, товарной группе или среднему чеку.

### Данные, которые вводит пользователь

| Поле | Обязательность | Описание |
|---|---|---|
| Название товара / группы | Да | Например: «Постельное бельё», «Куртки», «Обувь осень». |
| Категория | Да | Одежда, обувь, текстиль, товары для дома. |
| Розничная цена до акции | Да | Цена продажи до скидки. |
| Закупочная цена / себестоимость | Желательно | Если неизвестна, пользователь может ввести наценку. |
| Наценка, % | Альтернатива себестоимости | Используется, если закупочная цена неизвестна. |
| Остаток, шт. | Желательно | Помогает понять, хватит ли товара на акцию. |
| Текущие продажи, шт. за период | Да | Сколько продаётся без акции. |
| Средний чек до акции | Если расчёт по чеку | Для акций на чек. |
| Среднее количество единиц в чеке | Желательно | Нужно для механик комплекта и допродажи. |
| Сезонность | Да / Нет | Влияет на предупреждения. |
| Товар медленно продаётся | Да / Нет | Влияет на выбор механик. |
| Товар ходовой | Да / Нет | Влияет на риск слишком большой скидки. |

### Что рассчитывается автоматически

- себестоимость, если пользователь ввёл наценку;
- наценка, если пользователь ввёл себестоимость;
- валовая маржа до акции;
- валовая прибыль с единицы до акции;
- базовая выручка за период;
- базовая валовая прибыль за период;
- предупреждение о нереалистичной наценке;
- предупреждение о слишком низкой марже.

Для каждой акции считаются:

- выручка после акции;

- прибыль после расходов;
- изменение прибыли к базовому варианту;

- запас прочности;
- риск по марже;
- риск по остатку;
- итоговый балл.

### Итоговый балл акции

Предлагаемая логика оценки по 100-балльной шкале:

- до 35 баллов — прибыльность;
- до 20 баллов — безопасность скидки;
- до 15 баллов — реалистичность нужного роста продаж;
- до 10 баллов — достаточность остатка;
- до 10 баллов — простота запуска;
- до 10 баллов — соответствие цели акции.

Рекомендация:

- 80–100 баллов: сильный вариант;
- 60–79 баллов: можно запускать после проверки рисков;
- 40–59 баллов: слабый вариант, нужны правки;

## 14. Лист `06_Безопасная_скидка`

Назначение: показать, какую скидку можно дать без убытка и без критичного падения прибыли.

### Логика безопасной скидки

Есть два уровня безопасности:

1. **Скидка без продажи ниже себестоимости** — цена после скидки должна быть выше себестоимости.
2. **Скидка без потери целевой прибыли** — прибыль после акции должна быть не ниже установленного порога, например 90% от прибыли до акции.

Таблица должна показывать:

- максимальную скидку до себестоимости;
- максимальную скидку для сохранения минимальной маржи;
- максимальную скидку для сохранения прибыли при заданном росте продаж;
- рекомендуемую скидку, которая берёт самый осторожный из этих вариантов.

Если расчёт показывает, что безопасная скидка меньше планируемой, пользователь видит предупреждение.

## 15. Лист `07_Рост_продаж`

Назначение: рассчитать, насколько должны вырасти продажи, чтобы акция не ухудшила прибыль.

### Логика расчёта минимального роста продаж

Таблица сравнивает базовую прибыль без акции с прибылью после скидки и расходов.

Если пользователь снижает цену, прибыль с одной единицы товара падает. Значит, нужно продать больше единиц, чтобы компенсировать скидку.

Лист показывает:

- сколько штук продавалось до акции;
- сколько штук нужно продать после акции для сохранения прибыли;
- какой рост продаж нужен в штуках;
- какой рост продаж нужен в процентах;
- хватит ли остатка товара;
- реалистичен ли такой рост.

Оценка реалистичности:

- рост до 20% — обычно реалистично при хорошем товаре и нормальном анонсе;
- рост 21–50% — возможно, но нужны продвижение, выкладка и работа продавцов;
- рост 51–100% — высокий риск;
- рост выше 100% — запускать только при сильном поводе, большом трафике или распродаже остатков.

## 20. Основные формулы

Ниже формулы указаны в логике Google Таблиц / Excel. Конкретные адреса ячеек задаются на этапе сборки шаблона.

### 20.1. Себестоимость из наценки

Если пользователь знает цену и наценку:

```text
Себестоимость = Цена / (1 + Наценка%)
```

Пример: цена 1 800 руб., наценка 80%.

```text
Себестоимость = 1800 / 1,8 = 1000 руб.
```

### 20.2. Наценка из цены и себестоимости

```text
Наценка% = (Цена - Себестоимость) / Себестоимость
```

### 20.3. Валовая маржа

```text
Валовая маржа% = (Цена - Себестоимость) / Цена
```

Важно: наценка и маржа — не одно и то же. При наценке 80% маржа будет около 44,4%.

### 20.4. Валовая прибыль с единицы до акции

```text
Валовая прибыль с единицы до акции = Цена до акции - Себестоимость
```

### 20.5. Цена после процентной скидки

```text
Цена после скидки = Цена до акции * (1 - Скидка%)
```

### 20.6. Цена после фиксированной скидки

```text
Цена после скидки = Цена до акции - Скидка в рублях
```

### 20.7. Валовая прибыль с единицы после акции

```text
Валовая прибыль с единицы после акции = Цена после скидки - Себестоимость - Себестоимость подарка/бонуса на единицу
```

### 20.8. Базовая выручка

```text
Базовая выручка = Цена до акции * Количество продаж до акции
```

### 20.9. Прогноз продаж после акции

```text
Продажи после акции = Продажи до акции * (1 + Ожидаемый рост продаж%)
```

### 20.10. Выручка после акции

```text
Выручка после акции = Цена после скидки * Продажи после акции
```

### 20.11. Базовая валовая прибыль

```text
Базовая валовая прибыль = (Цена до акции - Себестоимость) * Продажи до акции
```

### 20.12. Валовая прибыль после акции

```text
Валовая прибыль после акции = (Цена после скидки - Себестоимость - Себестоимость подарка/бонуса на единицу) * Продажи после акции
```

### 20.13. Итоговая прибыль после расходов на акцию

```text
Итоговая прибыль после акции = Валовая прибыль после акции - Расходы на рекламу - Дополнительные расходы
```

### 20.14. Изменение выручки

```text
Изменение выручки, руб. = Выручка после акции - Базовая выручка
Изменение выручки, % = Изменение выручки, руб. / Базовая выручка
```

### 20.15. Изменение прибыли

```text
Изменение прибыли, руб. = Итоговая прибыль после акции - Базовая валовая прибыль
Изменение прибыли, % = Изменение прибыли, руб. / Базовая валовая прибыль
```

### 20.16. Точка безубыточности по количеству продаж

```text
Нужное количество продаж = (Базовая валовая прибыль + Расходы на акцию) / Валовая прибыль с единицы после акции
```

Если валовая прибыль с единицы после акции меньше или равна нулю, таблица должна показать: «Акция убыточна с каждой продажи».

### 20.17. Минимальный рост продаж для сохранения прибыли

```text
Минимальный рост продаж, шт. = Нужное количество продаж - Продажи до акции
Минимальный рост продаж, % = Минимальный рост продаж, шт. / Продажи до акции
```

### 20.18. Максимальная скидка до себестоимости

```text
Максимальная скидка до себестоимости% = 1 - (Себестоимость / Цена до акции)
```

### 20.19. Максимальная скидка для минимальной маржи

```text
Минимальная цена для маржи = Себестоимость / (1 - Минимальная маржа%)
Максимальная скидка для маржи% = 1 - (Минимальная цена для маржи / Цена до акции)
```

### 20.20. Максимальная скидка для сохранения целевой прибыли

```text
Целевая прибыль = Базовая валовая прибыль * Минимально допустимая прибыль после акции%
Допустимая прибыль с единицы после акции = (Целевая прибыль + Расходы на акцию) / Продажи после акции
Минимальная цена после скидки = Себестоимость + Себестоимость подарка/бонуса на единицу + Допустимая прибыль с единицы после акции
Максимальная скидка для прибыли% = 1 - (Минимальная цена после скидки / Цена до акции)
```

### 20.21. Рекомендуемая безопасная скидка

```text
Рекомендуемая безопасная скидка = MIN(
  Максимальная скидка до себестоимости,
  Максимальная скидка для маржи,
  Максимальная скидка для прибыли,
  Максимально допустимая скидка из настроек
)
```

### 20.22. ROI акции

```text
ROI акции = (Итоговая прибыль после акции - Базовая валовая прибыль) / Расходы на акцию
```

Если расходы на акцию равны нулю, вместо ROI показывать текст: «Расходов на акцию нет».

### 20.23. Запас прочности

```text
Запас прочности = Прогноз продаж после акции - Нужное количество продаж
```

### 20.24. Итоговая рекомендация

```text
Если Итоговая прибыль после акции < 0 → Не запускать
Если Валовая прибыль с единицы после акции <= 0 → Не запускать
Если Планируемая скидка > Рекомендуемая безопасная скидка → Опасно, снизьте скидку
Если Итоговая прибыль после акции >= Базовая валовая прибыль → Можно запускать
Если Итоговая прибыль после акции >= Базовая валовая прибыль * Минимальный порог → Можно тестировать осторожно
Иначе → Не запускать без изменения условий
```

## 21. Проверки ошибок

Таблица должна проверять данные до расчёта и после расчёта.

### Ошибки ввода

- не заполнена цена;
- не заполнена себестоимость и не заполнена наценка;
- цена равна нулю;
- себестоимость выше цены;
- скидка больше 100%;
- скидка отрицательная;
- продажи до акции равны нулю;
- расходы отрицательные;
- остаток меньше прогнозных продаж;
- выбранной механики нет в библиотеке.

### Финансовые ошибки

- цена после скидки ниже себестоимости;
- валовая прибыль с единицы после акции ниже нуля;
- прибыль после акции ниже допустимого порога;
- расходы на акцию слишком велики относительно прибыли;
- нужный рост продаж выше 100%;
- нужный рост продаж превышает доступный остаток.

### Логические ошибки

- выбрана механика «подарок», но не указана себестоимость подарка;
- выбрана акция на второй товар, но не указана средняя цена второго товара;
- выбрана бесплатная доставка, но не указана стоимость доставки;
- выбрана акция на базу клиентов, но база отсутствует;
- выбрана акция для распродажи остатков, но остаток маленький.

## 22. Предупреждения пользователю

Предупреждения должны быть написаны простым языком.

Примеры текстов:

- «Скидка выглядит слишком высокой для этой маржи. Проверьте себестоимость».
- «Выручка растёт, но прибыль падает. Такая акция может создать оборот без денег».
- «Чтобы акция окупилась, продажи должны вырасти больше чем на 50%. Это высокий риск».
- «Остатка товара не хватит для нужного объёма продаж».
- «Наценка выше 120%. Такое бывает, но для малого бизнеса это не стоит считать нормой».
- «Наценка 150% и выше выглядит завышенной. Проверьте закупочную цену и розничную цену».
- «Прибыль с каждой продажи после скидки отрицательная. Такую акцию запускать нельзя».
- «Акция подходит только для ограниченного списка товаров, а не для всего магазина».
- «Перед запуском проверьте, смогут ли продавцы предложить допродажу».

## 23. Логика итоговой рекомендации

Итоговая рекомендация должна состоять из четырёх частей:

1. Статус.
2. Короткое объяснение.
3. Что изменить, если акция рискованная.
4. Что проверить перед запуском.

### Статусы

| Статус | Цвет | Значение |
|---|---|---|
| Можно запускать | Зелёный | Акция сохраняет или увеличивает прибыль. |
| Можно тестировать | Жёлто-зелёный | Прибыль немного ниже базы, но в допустимом коридоре. |
| Осторожно | Жёлтый | Нужен сильный рост продаж или есть риск по марже. |
| Опасно | Оранжевый | Акция может ухудшить прибыль. |
| Не запускать | Красный | Акция убыточна или требует нереалистичного роста продаж. |

### Примеры рекомендаций

- «Можно запускать. При заданных условиях прибыль после акции выше базовой на 8%. Проверьте остаток товара и подготовьте выкладку».
- «Можно тестировать осторожно. Прибыль ниже базовой на 5%, но акция может помочь распродать сезонный остаток».
- «Опасно. Скидка 30% требует роста продаж на 85%. Лучше снизить скидку до 15% или заменить её подарком от суммы чека».
- «Не запускать. Цена после скидки ниже себестоимости. Каждая продажа будет приносить убыток».
