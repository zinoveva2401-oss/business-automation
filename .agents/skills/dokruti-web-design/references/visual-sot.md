# DOKRUTI Visual SOT and adaptive visual direction

Status: operational routing contract refreshed 2026-09-23 from the active owner task and current Business System records. Live sources supersede this file; this file does not copy private operating data.

## Stable brand DNA

Preserve the current `02_Бренд-система` and `03_Активы_проекта` invariants:

- master brand `Докрути` / `DOKRUTI`;
- the master visual principle `ДОКРУТИ + orange След + result point`, used meaningfully rather than decoratively;
- current brand palette and approved visual/likeness boundaries;
- clear movement from a real problem and its cause through checking to a useful solution/action;
- human, credible founder presence and truthful asset provenance;
- Visual Event First, Remove-Text Test, motion QA and anti-degradation checks as production principles.

The exact colors, typography, asset approvals and current wording must be confirmed in the live sources for the task. This list does not freeze a layout, image style, motion pattern, color recipe, donor, or composition.

## Adaptive visual mechanics

The current visual mechanic is selected per task after inspecting the live `Референсы` library, Business System `11_КОНКУРЕНТЫ_И_РЕФЕРЕНСЫ`, current web examples, task context and applicable fresh research. SYPartners, NOBL, 11point2 and all other external references are optional donors, never permanent authority. Their use, rejection, adaptation and non-copy boundaries must be recorded for each substantial design.

Hold stable DOKRUTI DNA while allowing composition, density, typography, imagery, color balance, navigation, interaction and motion to change when a stronger current solution serves the page. Do not reproduce a historical approved or rejected concept as authority unless the owner explicitly locks it for this task.

## Required decision record

For each substantial design, record:

`CURRENT PAGE / USER JOB → LIVE SOURCE FINDINGS → CANDIDATE DONORS → SELECTED MECHANICS → BRAND FIT → USER VALUE → ATTENTION → CONVERSION → PERFORMANCE / ACCESSIBILITY → DOKRUTI ADAPTATION → WHAT NOT TO COPY → SECTION / ROUTE`.

Also record the first-screen visual-hook test: when most explanatory copy is mentally removed, does a distinct visual idea/event remain? If not, the concept fails before implementation. Confirm current asset provenance and status separately from visual suitability.
