# Owner gates

## Назначение
Обращайся к владельцу только за решением, которое нельзя безопасно вывести из утверждённых правил.

## Рабочая процедура
Продолжай низкорисковую обратимую работу, когда source/claim/rights/capability подтверждены. Gate обязателен для изменения frozen brand/strategy/product/legal решений; новой личной истории/identity; отсутствующего owner-only fact/asset; затрат; OAuth/credentials; высокорискового legal/financial вопроса; необратимой публикации/удаления без прямого разрешения. Различай draft approval и publish authorization.

## Выход и gate
Формат: конкретный выбор → почему важен → варианты и последствия → рекомендация → что изменится. Фиксируй scope/decider/date/expiry. Не эскалируй crop, микрокопирайт и safe technical choices. При gate удержи side effect, сохрани checkpoint, продолжай независимые lanes.
