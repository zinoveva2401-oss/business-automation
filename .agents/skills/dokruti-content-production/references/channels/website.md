# Channel profile: Website

## Native adaptation
Сделай evergreen material с уникальной пользой, ясной структурой, источниками, релевантными internal links и подтверждённой авторской датой. Schema/CTA совпадает с видимым content.

## Capability and publication contract
Используй существующий article/site pipeline. Проверь source → rendered page: canonical/indexability, links, mobile layout, alt, schema, consent/form. После разрешённого deploy проверь production URL; локальный build недостаточен.

## Fallback and recovery
Без release authorization не публикуй. После deploy читай exact live page; Git SHA не является readback.

## Required record
Сохрани parent master/revision, channel, native format, draft hash, capability evidence/date, rights/disclosure, idempotency key, status, external readback и next step. Динамические platform rules и доступ проверяются во время исполнения; этот профиль сам не доказывает актуальную capability.
