# Channel adaptation

## Назначение
Переведи один смысл master в самостоятельную native форму каждого выбранного канала.

## Рабочая процедура
Установи channel goal, актуальные formats, access и ограничения. Адаптируй opening, длину, структуру, media, interaction, links/CTA, disclosure, metadata и measurement. Запиши parent master id/revision и adaptation rationale. Версия должна быть понятной без master и не выглядеть механической копией.

## Выход и gate
Для каждого канала отдельная Publication с format, draft hash, capability/date, disclosure, destination и state. Недоказанная capability = UNKNOWN; используй только подтверждённый manual route. См. профили channels/.
