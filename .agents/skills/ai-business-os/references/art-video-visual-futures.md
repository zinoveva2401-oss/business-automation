# Art Direction / UX / Video / Visual Futures

## Source hierarchy
Current `02_Бренд-система` and `08_Дизайн-система_продуктов` outrank old retail visual packs.

## Core quality
Adult editorial character, real business environment, materiality, causality, proof and movement to result.
`VISUAL EVENT FIRST → INFORMATION INSIDE EVENT`.
`REMOVE-TEXT TEST` for meaningful scenes.

## No single permanent trick
Do not reduce brand to torn paper, orange trace, Mini-Svetlana, one collage style or a single master reference. These are tools, not a prison.

## Visual Futures Radar
Track:
- editorial/web/product design;
- motion and scroll interaction;
- information design;
- AI-native visual production;
- typography/layout;
- photography/mixed media;
- commerce/product visualization;
- video language.

Classify mechanism:
`CURRENT / EMERGING / EXPERIMENTAL`.
Then:
`brand fit / meaning / usability / production cost / accessibility / prototype / adopt or reject`.

Do not claim to predict 2028 with certainty. Aim to identify early signals and test them before they become generic.

## Product Art Direction
Art director enters before final production, not after writing. Create real content prototype pages/screens. Visuals must help comprehension and perceived value.

## Content visuals
Art direction works from Marketing Matrix + editorial narrative. Choose still/carousel/motion/video based on meaning. For public channel assets also design the first visual event and the cover/thumbnail/profile handoff when relevant; use [Channel Experience / Packaging](channel-experience-packaging.md).

## Video / creative direction
Workflow:
`raw idea/source → goal+audience → current creative reference scan → hook/route options → script/beat sheet → visual concept → founder shoot-card/source plan → storyboard/edit plan → production route → first cut → creative/media critic → repair → final candidate → cover/thumbnail → platform variants → QA`.

Use [Creative Content Production](creative-content-production.md) for route/hook/production orchestration and [Media Production Quality](media-production-quality.md) for time-based QA.

Motion-carousel, animated still, split-layout, talking-head+screen, kinetic typography and other mechanics are candidates, not permanent brand templates. Choose by meaning, current evidence and platform fit.

For meaningful time-based media, apply [Media Production / Video / Motion / Audio Quality](media-production-quality.md): pacing, visual proof, audio clarity, caption safe-zones, aspect-ratio recomposition, actual export review, source hygiene and independent media critique.

No motion for motion's sake. Reduced motion/accessibility where applicable.

## Premium e-book visuals
Use design system, chapter rhythm, diagrams, scenarios, decision maps, real examples and controlled visual variety. Do not fill every page with cards.

## QA
Check actual exported files/screens, not only spec: readability, crop, mobile, branding, contrast, artifacts, file weight, motion, text accuracy.


## Media production operations

When content begins as voice/video, plan the shortest production chain that preserves quality:
`capture → source storage → transcription → script/edit → sound cleanup → captions → edit → clips/resizes → export → QA → publish/hand-off → archive`.

When choosing Descript/Adobe/Remotion/HyperFrames/HeyGen or other tools, compare actual quality, Russian-language support, speed, cost/quota, device load, export portability and re-editability. Do not build a media studio more complex than the publishing goal requires.
## Visual Delivery Contract for owner-facing business artifacts

Svetlana evaluates complex work visually. For substantial strategy/product/commercial/system artifacts, the art/UX contour must decide how the result is best understood by sight, not merely how it is written.

Examples:
- commercial architecture → visual revenue map + funnel + channel/product matrix;
- product strategy → product ladder/map + customer path + package preview;
- marketing system → funnel + content-to-revenue map + channel matrix;
- process/system → flowchart/mind-map/state map;
- research → competitor landscape + comparison matrix + evidence-backed opportunity map.

A Markdown/document master may remain the canonical text source, but if the owner's decision depends on understanding structure, the owner-facing deliverable must include a visual representation in a format the current environment can actually produce and verify.

Do not create decorative diagrams. Every visual must reduce cognitive load or expose relationships, gaps, priorities, flow or customer experience.

## Finished-product design gate

The design contour does not stop at a style description. It must inspect actual final/near-final pages, screens, files or rendered outputs. If a product is supposed to feel premium, generic document styling, repeated cards, tiny tables, raw spreadsheets, template-like AI visuals or unformatted Markdown are Major defects when they materially reduce perceived value or comprehension.

The owner should review the finished experience, not act as the art director for obvious layout/visual problems.

## Mandatory design-thinking gate

For new/materially redesigned visual systems, use [design-thinking-visual-system.md](design-thinking-visual-system.md): define the communication problem, research reference principles, generate materially different routes, converge on one dominant visual idea, test representative real-content screens and use an independent visual critic. A palette swap or card rearrangement is not a new concept.

## Universal output-design gate

For every meaningful owner/customer/public artifact where presentation affects comprehension or action, use [universal-output-design.md](universal-output-design.md). This includes posts, visual posts/carousels, documents, checklists, workbooks, dashboards, presentations, commercial proposals, product cards, research maps and web artifacts. Composition follows the customer/communication job and target surface; actual output is rendered and inspected.

## Publication design gate

For books/manuals/long-form, additionally use [publication-design-ebook.md](publication-design-ebook.md). Layout follows meaning: prose stays prose, process becomes sequence, comparison becomes table only when useful, tools show real interfaces, and cards are not the default container. Test continuous reading, not isolated pages.
