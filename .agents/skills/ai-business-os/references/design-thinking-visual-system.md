# Design Thinking / Visual Concept / Independent Art Critique Contract

## Purpose

Prevent the system from producing technically neat but generic AI layouts. The design contour must solve a communication problem, not merely style components.

## 1. Design problem definition

Before concepts, define:
- audience and context of use;
- single primary business/communication goal;
- what must be understood in the first 5 seconds;
- desired brand perception;
- dominant tension or idea;
- what evidence/material already exists;
- constraints: content density, mobile, accessibility, production cost, assets;
- anti-goals: what the result must not resemble.

## 2. Visual research, not inspiration dumping

Study a sufficiently broad reference field from current public sources when the task warrants it.
For each useful reference extract principles, not pixels:
`hierarchy / composition / typography / image logic / rhythm / interaction / density / mobile behavior / why it works / what is transferable / what would be wrong for DOKRUTI`.

Do not let one favorite reference dominate the result by accident.
Do not copy a distinctive composition 1:1.

## 3. Concept generation

For substantial new visual direction, internally generate several materially different routes before convergence.
A route must differ by the governing visual idea, not just colour/photo swaps.

Each route states:
- one-sentence concept;
- dominant visual mechanism;
- typography logic;
- image/material logic;
- layout/rhythm logic;
- mobile adaptation principle;
- strengths / risks / brand fit / production cost.

The system may self-select the strongest route when evidence clearly distinguishes it. Owner choice is required only when the remaining choice is strategically/subjectively material under the Owner Gate rules.

## 4. One dominant idea

A strong page/product normally has one dominant visual idea at a time.
Do not combine collage + dashboard + giant type + 3D + torn paper + neon data + motion merely to look "creative".

`ONE VISUAL EVENT → SUPPORTING INFORMATION`.

## 5. Composition and hierarchy gates

Check:
- eye enters at the intended point;
- primary/secondary/tertiary information is obvious;
- whitespace creates grouping, not emptiness;
- alignment/grid is deliberate even when asymmetrical;
- image crop/focal point supports the message;
- typography creates hierarchy before colour does;
- repeated components have a reason;
- page rhythm changes with content function;
- desktop and mobile each feel composed, not auto-stacked.

## 6. Anti-cardification rule

Cards are justified only when content items are independent, scannable and comparable/actionable as units.

If content is sequential, narrative, hierarchical or relational, prefer prose, list, timeline, diagram, editorial composition, table, split layout, canvas or other appropriate form.

A screen where most meaning is represented as same-sized cards is automatically reviewed for template/SaaS drift.

## 7. Visual originality / brand tests

Run all applicable tests:
- `REMOVE-TEXT TEST` — without text/logo, does the scene still convey the intended situation or mechanism;
- `5-SECOND TEST` — is the core point/perception obvious quickly;
- `BLUR/SILHOUETTE TEST` — does hierarchy remain visible when detail is blurred;
- `GENERIC TEMPLATE TEST` — could the same layout be sold unchanged to 20 unrelated businesses;
- `BRAND MEMORY TEST` — is there at least one coherent visual behavior people could remember as DOKRUTI;
- `MOBILE INTENT TEST` — is mobile intentionally composed rather than only stacked;
- `REAL-ASSET TEST` — are real tools/evidence used where they build trust instead of generic icons/mock dashboards.

## 8. Independent visual critic

The producer/art director cannot be the only judge for substantial visual output.
A separate critic receives:
- original communication goal;
- frozen brand/source of truth;
- reference principles;
- actual full-size screens/pages;
- baseline when redesigning.

The critic returns `PASS / FAIL / UNKNOWN` for:
`concept strength / hierarchy / originality / brand fit / usability / mobile / semantic component choice / AI-template risk / production realism`.

A technical PASS cannot override visual FAIL.

## 9. Visual system freeze

After the concept proves itself on representative real-content screens/pages, freeze:
`type system / spacing rhythm / colour roles / image logic / component semantics / interaction principles / mobile rules`.

Later pages may vary composition but must inherit the system. Do not force identical templates where content type differs.
