# Strategic Intelligence / Opportunity Gate v2.0.9

## Purpose

Prevent the factories from professionally producing weak, stale or badly formatted ideas.

Strategic Intelligence thinks and selects. It does not write the final book, article, site or video.

## 1. Sources

Use only relevant current sources, including:
- customer/VOC: situations, complaints, questions, objections, search language, reviews, support/refunds;
- market/substitutes: peers, concrete products, free content, AI, software, services, hiring, manual work, doing nothing;
- international/cross-industry scouting: methods, product mechanics, workflows, formats, open-source, cases;
- trends/platforms: official changes plus verified creator/business patterns;
- creative/visual/media intelligence: hooks, first-frame patterns, demonstrations, interaction mechanics, visual metaphors, formats and production patterns that can be tested without copying protected expression;
- methodology/professional basis;
- technology/tools: MCP/plugins/connectors/repos/models/automation;
- our data: content, search, site, product, sales, revenue, refunds, owner hours, stalled work;
- Svetlana's ideas/experience as signals that still require evidence when used for public/product claims.

## 2. Opportunity Card

The production input is not a broad topic. Use an evidence-backed opportunity card containing, as applicable:
`ID / source+date / concrete situation / customer language / buyer-user-payer / pain-or-desire / frequency-strength-urgency / what is already tried or bought / causes / alternatives / evidence+confidence / disconfirming evidence / methods/mechanics / donor patterns / our synthesis / transferability / format-fit / creative-visual-media direction when relevant / channel-fit / commercial-fit / risk-IP-legal / effort-cost / owner load / cheapest test / success-kill threshold / recommended route`.

## 3. Framework diversity

No single framework governs all content or products. Awareness/Hunt ladder is a routing model for customer state, not a mandatory article/product template.

Use the smallest useful combination of VOC/JTBD situation, awareness, causal analysis, solution/method fit, evidence, case/story, comparison, experiment and action path.

## 4. Format-fit gate

Do not promise an outcome the medium cannot deliver.

If the desired result requires demonstration, repeated practice, feedback, live correction or behavior training, a text-only book cannot claim full skill mastery. Route to the appropriate mix of text, visual lesson, interactive tool, trainer, course, service or stop the idea if that format contradicts strategy.

## 5. Cheap experiment before expensive build

If a critical assumption remains uncertain, test the riskiest question cheaply before full production.

Examples: targeted VOC/interviews, content probe, CTA/fake-door, waitlist, pre-order, landing, concierge/manual test, prototype/use test, technical proof-of-concept.

Each experiment has:
`baseline / primary metric / guardrail / threshold / horizon-or-sample logic / budget / stop rule / learning result`.

## 6. Priority Engine

Candidates receive `NOW / NEXT / LATER / TEST / HOLD / KILL` based on:
- money impact / critical blocker;
- evidence quality;
- leverage/unblock value;
- urgency/timing;
- effort/cost;
- owner hours;
- risk/reversibility;
- dependency readiness;
- cheap-test availability;
- conflict/cannibalization with current MAIN.

A fashionable signal is not automatically a task.

## 7. Donor/IP rule

Allowed: learn problem framing, mechanics, workflow, product architecture, customer journey, funnel, interface pattern, measurement and abstract principles.

Forbidden: copy protected text, code, design composition, brand, paid/closed method, files or confidential material 1:1.

Record what was learned as a principle and what is DOKRUTI's own implementation when provenance matters.

## 8. Output

Strategic Intelligence outputs a short evidence-backed decision:
`what we noticed / why it matters / what others do / what transfers / what does not / our proposed synthesis / cheapest test / route / kill rule / what source-of-truth must be updated`.

Then the Production Dispatcher routes to Product / Content / Growth / Site-Tech / Automation / Commercial experiment or `DO NOT PRODUCE`.
