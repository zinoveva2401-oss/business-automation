# Живое видео / чистка сырья / банк монтажных механик / тренд-разведка

## Назначение

Когда Светлана даёт живые видео/аудио, система должна работать как режиссёр монтажа и редактор речи: **понять смысл, найти лучшие дубли, убрать технический и речевой мусор, сохранить естественного человека, затем усилить визуально и звуком**.

Не заставлять Светлану самой говорить, где резать.

## 1. Инвентаризация сырья

До монтажа:
`файлы → длительность → ориентация/разрешение/fps → качество звука → лица/права/приватность → дубли → ключевые темы → лучшие фрагменты → технические дефекты`.

Если материала много — сначала индекс/транскрипт и контактный лист, а не многократная загрузка всего видео в сильную модель.

## 2. Монтаж по транскрипту

Сделай транскрипт с таймкодами и отметь:
- ложные старты;
- самоповторы;
- «ээ», «мм», «ну», «короче», другие паразитные вставки;
- слишком длинные паузы;
- оговорки;
- уход от темы;
- повтор уже сказанного другими словами;
- слабые вступления до сути;
- сильные естественные формулировки, которые нельзя «переполировать»;
- эмоционально важные паузы, которые нужно оставить.

После этого создай `бумажный монтаж`: какие фрагменты остаются и почему, прежде чем рендерить.

## 3. Правило естественности

Не вырезай каждую микропаузу и не превращай человека в робота. Редактируй по цели:
`понятность / темп / доверие / эмоция / удержание`.

Слова-паразиты удаляются, когда мешают. Естественная разговорная связка может остаться, если она поддерживает голос Светланы.

Если вырезание меняет смысл или создаёт ложное впечатление — запрещено.

## 4. Выбор лучшего дубля

Оцени дубли по:
`смысловой ясности / естественности / энергии / взгляду / дикции / звуку / свету / композиции / возможности смонтировать без артефактов`.

Можно собирать лучший итог из нескольких дублей, если смысл не искажается.

## 5. Техническая коррекция

По необходимости:
- стабилизация;
- кадрирование/reframe;
- баланс белого;
- экспозиция/контраст;
- умеренное шумоподавление;
- цветокоррекция;
- voice cleanup/de-noise/de-esser;
- выравнивание громкости;
- коррекция скорости в допустимых местах;
- безопасный AI relight/cleanup, если доступен и не искажает лицо/сцену.

Важно: монтаж не может восстановить информацию, которой физически нет. Сильно пересвеченное/смазанное/зашумлённое видео иногда лучше переснять. Система должна честно это сказать и выдать точную инструкцию пересъёмки.

## 6. Где нужны визуальные вставки

Для каждой важной фразы спроси: лучше ли её **показать**, а не только проговорить?

Кандидаты:
`B-roll / экран / сайт / таблица / документ / диаграмма / цифра / предмет / before-after / скриншот / фотография / короткая надпись / плашка / анимация / карта / интерфейс`.

Вставка должна доказать, объяснить или сменить ритм; декоративный шум не нужен.

## 7. Банк монтажных механик

Храни не чужие ролики и не «шаблон для копирования», а **карточки механик**:
`источник+дата / формат / первые 1–3 секунды / структура речи / средняя длина плана / тип склеек / punch-in / B-roll / текст / графика / звук / музыка / финал / почему работает / где не работает / права / оригинальная адаптация DOKRUTI / метрика теста`.

Минимальные семейства механик:
- чистый talking-head;
- динамичный jump-cut talking-head;
- talking-head + contextual B-roll;
- лицо + экран/демо;
- picture-in-picture/split layout;
- разбор кейса/экрана;
- история/мини-документалка;
- founder diary/build in public;
- вопрос→ответ;
- список/ошибки/мифы;
- before→after;
- реакция/комментарий/remix при наличии прав;
- UGC-style service/tool demo;
- tutorial/screen walkthrough;
- interview/podcast clip;
- data/motion explainer;
- cinematic brand story;
- meme/cultural reference where brand-safe;
- fast montage/photo montage;
- calm authority/slow editorial.

Выбор семейства идёт от смысла, аудитории и источников, а не от моды.

## 8. Откуда брать свежие референсы

Перед существенной short-form задачей радар может проверять актуальные источники:
- официальные trend/analytics/creative разделы платформ;
- собственную аналитику каналов;
- наблюдаемых похожих creator/business аккаунтов;
- специализированные trend/keyword/competitor инструменты;
- рекламные creative libraries/centers;
- поисковые тренды;
- профессиональные монтажные/creative сообщества.

Конкретные сервисы не являются вечной частью Skill. На 18.09.2026 применимыми примерами могут быть TikTok Creative Center/Top Ads/Trends, YouTube Studio Trends и breakout/content-gap данные, Google Trends, vidIQ trend alerts/competitor velocity, Instagram/Edits inspirations/templates. Перед использованием проверить актуальную доступность/регион/условия.

## 9. Trend card

Каждый найденный «залетающий» ролик переводится в карточку:
`SOURCE/DATE → AUDIENCE → TOPIC → HOOK → EDIT MECHANIC → AUDIO/TEXT → WHY IT MAY WORK → WHAT IS PLATFORM-SPECIFIC → DOKRUTI ORIGINAL VERSION → CHEAP TEST → METRIC → RESULT`.

Запрещено: «этот ролик набрал много просмотров, копируем». Нужно отделить тему, механику и распределение платформы.

## 10. Первый монтаж → критика → второй монтаж

Сравни первый и второй монтаж по конкретным параметрам:
`время до сути / пустые секунды / средняя длина плана / повтор / ясность / смена визуального доказательства / слышимость / читаемость / эмоциональный ритм / финальный payoff`.

Вторая версия должна иметь материально объяснимое улучшение, а не просто «другую музыку».

## 11. Обучение Светланы съёмке

Если проблема в исходнике, не ограничивайся монтажом. Дай короткую тренировку:
`камера/объектив → высота → расстояние → взгляд → свет → фон → звук → положение рук → паузы → темп → 2–3 дубля → B-roll`.

Система должна учить постепенно: один-два навыка на съёмку, а не 25 правил сразу.

## 12. Монтажная экономика

Сильная модель нужна для истории/смысла/отбора спорных мест. Повторяемые операции делай дешёвым маршрутом: транскрипт, таймкоды, ffmpeg, шаблонный reframe, рендер, громкость, технические проверки. Не расходуй сильное reasoning на каждый кадр.
