# Быстрые команды / Visual, Thinking & Production Palette

## Главный принцип

**Светлана не обязана помнить команды.** Business OS сам распознаёт возможность, выбирает лучший способ представления и либо применяет его, либо предлагает 1–3 действительно полезных маршрута. `/команды` показывает полный справочник только по запросу.

Это семантические команды Skill, а не обещание, что каждая поверхность ChatGPT имеет нативный slash-UI. Команда означает намерение и может быть выполнена доступным инструментом, плагином, кодом, текстовой спецификацией или передана подходящему исполнителю.

## Автовыбор

1. Один очевидный, обратимый, дешёвый маршрут → применить автоматически и коротко назвать его.
2. 2–3 существенно разных сильных маршрута → показать только их: `команда / как будет выглядеть / зачем / что получим`.
3. Высокая стоимость/публичный риск/необратимость → показать preview до исполнения.
4. Capability отсутствует → не притворяться: создать production-ready brief/mockup/spec и выбрать доступного исполнителя.
5. Если ни одна сохранённая команда не подходит, агент может предложить **временную смысловую команду** для текущей задачи, но не обязан добавлять её в Skill. Повторяемая полезная команда проходит Learning Promotion.

## Capability routes

Выбирай по текущим инструментам, а не по привычке. Возможные маршруты в текущей экосистеме могут включать diagrams/FigJam, Figma, Adobe mockups, Canva, fal image/video/3D, Remotion/HyperFrames, image generation, code/prototypes, maps, docs, spreadsheets and native text/table outputs. Перед обещанием исполнения проверь фактическую доступность.

## Preview contract

Перед дорогой генерацией, когда выбор materially changes result, покажи compact preview:
`форма → композиция/scene → key elements → interaction/motion → что пользователь поймёт/почувствует/сделает`.

Preview не становится owner gate, если выбор обратим и не меняет бизнес-смысл/стоимость/риск.

## Command-learning contract

Палитра **расширяемая, а не исчерпывающая**. Если агент трижды видит повторяемую полезную команду, которой нет в банке, он создаёт candidate learning: `название / триггер / ожидаемый результат / tool route / examples / conflicts`. В stable Skill команда попадает только после review/regression.

## Autoprompt memory rule r5

Agent должен предлагать эти команды **не как синтаксис для запоминания**, а как возможные действия. Пример: «Здесь полезнее не ещё одна таблица, а `/контент-панель`: неделя/месяц, preview, статус, канал и метрики на одном экране. Я бы выбрал её автоматически». Если команда очевидна и безопасна — сразу применить без вопроса.
