# Media Production / Video / Motion / Audio Quality Contract v2.0.10

## Purpose

Define professional quality for video, motion, voice, podcast-like audio and derived clips so the system does not stop at “script + captions + export”.

Apply when the deliverable contains meaningful time-based media.


## Raw talking footage / transcript-first editing

Для живого материала Светланы обязательна ссылка на [Живое видео / чистка сырья / банк монтажных механик](raw-footage-editing-trend-bank.md). Не жди от владельца таймкодов «где резать»: сам транскрибируй/индексируй, найди ложные старты, повторы, паразитные вставки, лишние паузы, уходы от темы и лучшие дубли; сохрани естественные смысловые паузы и голос. Сначала бумажный монтаж по смыслу, затем рендер.

## 1. Media job before tool

Define:
`audience / business-content goal / platform / duration / viewer start state / viewer end state / primary action / source assets / brand role / emotional register / production budget / owner participation`.

Choose tools only after the media job is clear. Do not add avatars, 3D, motion or AI effects merely because they are available. Route by current capability and evidence, not vendor loyalty.

For local multi-source media, first inventory files, duration, orientation, audio, quality, privacy/rights and where the sources may safely be processed. Family/private media must not be copied into a public repo or persistent shared workspace merely for convenience.

## 2. Producer / story / pacing

Before editing define:
- media purpose and audience emotion/decision;
- hook/opening promise or emotional opening;
- narrative/teaching/emotional beats;
- source hierarchy and what each shot proves/feels;
- visual proof/examples;
- pacing changes and intentional breathing room;
- payoff/climax;
- ending/CTA when needed.

For meaningful video create an edit plan/beat sheet before heavy rendering. A codec demo or sequence of technically valid scenes is not evidence of professional editing.

Cut repetition, dead air and filler, but do not make speech unnaturally rushed.
Short clips need one complete idea, not a mutilated excerpt that loses context.

## 2.1. Founder / on-camera shoot card

When Svetlana must record new material, provide a compact shoot card before capture: `script/beats / duration / framing / camera height / orientation / location-background / light / audio / wardrobe direction / props-screen / energy-pauses / alternate takes / B-roll inserts / privacy-brand avoidances`.

The goal is to avoid owner re-shoots caused by missing production planning.

## 2.2. Edit grammar

Use edit techniques only when they serve story/retention/clarity. Candidate grammar may include cutaways, punch-ins, J/L audio bridges, screen inserts, B-roll, still-photo animation, kinetic text, purposeful speed changes, match/graphic transitions and sound bridges.

Do not turn the checklist into mandatory effects. Repetitive default crossfades, random zooms and constant motion are not “modern editing”.

## 3. Visual language

- storyboard/shot logic supports meaning;
- B-roll, screen recordings, diagrams and text overlays prove/explain rather than decorate;
- motion has a semantic purpose;
- typography and captions respect mobile safe zones;
- transitions are consistent and restrained;
- generated visuals are checked for artifacts, wrong text, anatomy/object errors and brand mismatch;
- aspect-ratio adaptations are recomposed, not blindly cropped.

## 4. Audio quality

Check actual listening output:
- speech intelligibility;
- noise/reverb/clicks;
- consistent perceived loudness across segments;
- music does not mask speech; use intentional level/ducking/mix rather than simply layering tracks;
- no abrupt cuts/pops;
- stereo/mono compatibility as relevant;
- pronunciation of names/terms/numbers;
- synthetic voice quality and Russian-language naturalness when AI voice is used.

Do not fabricate a universal loudness target when the delivery platform has different requirements; use current platform/spec when material.

## 5. Captions and on-screen text

- captions match spoken meaning and names/numbers;
- readable size, contrast and safe margins;
- sensible phrase segmentation;
- not too many words on screen at once;
- on-screen text does not duplicate every spoken word when a concise takeaway is better;
- burned-in vs sidecar captions follow delivery needs.

## 6. Accessibility and comfort

- captions/transcript when appropriate;
- reduced-motion alternative or restrained motion when needed;
- avoid flashing/flicker risks;
- key information is not conveyed by colour alone;
- visual/audio density remains understandable on the target device.

## 7. First cut → critique → final export

For substantial video, the first technically complete render is `FIRST CUT`, not final. Run a media/creative review against the original job, record concrete defects/opportunities, make a consolidated repair and render a `SECOND CUT / RELEASE CANDIDATE` when improvement is material.

Inspect the actual final exports:
`resolution / aspect ratio / codec-container / audio / frame glitches / subtitle sync / text crop / safe zones / duration / file size / thumbnail-cover / platform upload preview`.

Where possible preserve evidence of what changed from first cut to final candidate; the purpose is improvement, not ceremonial version count.

When multiple platform variants are promised, open each representative export. A master timeline rendering correctly is not evidence that every crop/clip is correct.

## 8. Re-editability and source hygiene

For meaningful reusable media preserve:
- source assets;
- project/timeline or reproducible composition source when feasible;
- licenses/rights for music, stock and third-party assets;
- transcript/captions;
- final exports;
- version naming.

Do not trap a core business asset in an unrecoverable vendor-only format without a justified reason.

## 9. Independent media review

For substantial video/audio output, a separate review pass checks:
`producer/story arc / hook or emotional opening / pacing / clarity / visual proof / source variety / edit grammar / audio/music/SFX / captions / brand / cover-thumbnail / mobile-platform fit / artifacts / export integrity / rights/privacy`.

Technical render success alone is not PASS. A short synthetic pipeline fixture may prove capability, but it cannot certify producer/director/editor quality.

## Portfolio-grade media

For DOKRUTI public/founder media, apply [live-portfolio-proof.md](live-portfolio-proof.md). Technical correctness is not enough: the cut must demonstrate producer/editorial judgment, purposeful motion/sound, platform-native presentation and enough distinctiveness that it can serve as future service proof. This does not require expensive effects on every video; concept and editing intelligence matter more than decoration.
