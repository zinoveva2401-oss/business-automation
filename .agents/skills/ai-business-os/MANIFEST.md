The broad scouting shape is `100+ observations → ~30 candidates → ~10 strong donors → 3–7 signals → 1–3 tests` when budget and source access permit. This is a funnel principle, not a forced daily quota. The system reports coverage gaps rather than pretending a narrow scan is global.

The seven donor classes are now explicit: `PRODUCT / OFFER / CONTENT / FORMAT / HOOK / BUSINESS MODEL / DISTRIBUTION`. Every strong international donor must pass `GLOBAL TRACTION → RU GAP → TRANSFER FIT → TESTABILITY`; the owner-facing chain is `SIGNAL → MECHANIC → RU GAP → ORIGINAL DOKRUTI ADAPTATION → MONEY ROUTE → TEST → LEARNING`.

r9 does **not** introduce another Radar/Signals/Ideas spreadsheet or owner-facing workflow. It writes into existing canonical Business/Content/competitor-reference/product-hypothesis/experiment/decision objects using Entity Resolution / Update-in-Place.
