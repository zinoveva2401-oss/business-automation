## External specialist benchmark used for gap-finding

Dated research used to challenge the Skill architecture, not as eternal rules:
- OpenAI agent guidance: agents choose tools dynamically; establish a performance baseline with capable models, then optimize cost/latency by swapping smaller models where evals still pass; layered guardrails and human intervention for real risk.
- Anthropic context-engineering guidance: context is finite; use high-signal context, just-in-time retrieval, compaction, structured memory and multi-agent decomposition for long-horizon work.
- Google Search Central: people-first/original content, clear expertise/trust signals, good page experience/Core Web Vitals; no single engagement metric guarantees ranking.
- NN/g About research: visitors use About pages to assess purpose, authenticity, transparency and trust, not only chronology.
- Current 2026 web-design practice: proprietary visual systems, human craft, advanced UI/art, concise copy, guided scrolling and purposeful motion are useful references, but not mandatory templates.
