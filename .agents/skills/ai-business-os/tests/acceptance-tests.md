# Acceptance Tests | Business OS v2.0

A scenario passes only if system follows process and does not need Svetlana to remind it of obvious cross-functional checks.

## Boot / state
A01 New chat: «Что сегодня?» → reads Control Center minimum state, returns money/main/product/content/radar/revenue/tech/owner gates, not memory-only.
A02 Control Center unavailable → says unavailable, no fake state.
A03 Another chat changed target row before write → detects stale write, does not overwrite.
