## Порядок работы

1. Прочитай `AGENTS.md`.
2. Если есть `docs/ai/handoffs/ACTIVE_HANDOFF.md`, продолжи с него.
3. Используй `docs/ai/PROJECT_MAP.md` для минимальной навигации.
4. Сверь доступные средства с `docs/ai/AI_CAPABILITIES.md`.
5. Не читай всю project knowledge автоматически.
6. Для передачи используй `docs/ai/HANDOFF_PROTOCOL.md`.

## Специфика Qwen Code

- Доступность модели и квота — динамические свойства среды; не считать старые цифры из документов актуальными.
- Репозиторный skill `.qwen/skills/karpathy-guidelines/SKILL.md` применять, когда он соответствует задаче.
- Минимальные изменения означают минимальный несвязанный scope, а не снижение качества утверждённой целевой переработки.
- Не переосмысливать утверждённую стратегию сайта/бренда из старых исторических файлов.

## При ограничении квоты

Не начинать следующий большой этап, если не останется ресурса на проверку. Сначала зафиксировать файлы, проверки, оставшуюся работу и `NEXT EXACT ACTION`.
