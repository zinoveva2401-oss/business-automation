# QWEN.md — адаптер Qwen Code

Статус: действующий model-specific adapter.
Проект: `Докрути`.

Qwen Code использует [`AGENTS.md`](AGENTS.md) как единый контракт и [`docs/ai/SOURCE_MANIFEST.md`](docs/ai/SOURCE_MANIFEST.md) как маршрут к актуальному live-контексту. Этот файл не переопределяет общий контракт и не является бизнес-источником.

## Порядок

1. Определи класс задачи и прочитай минимально необходимый контекст.
2. Для существенной работы проверь live Google Drive/Sheets по source manifest; не принимай repo-копии за текущие цены, продукты, статусы или брендовые решения.
3. Используй доступные Skills, subagents, MCP и tools по реальному риску задачи.
4. Выполни нужный production/QA loop, independent review и regression до handoff.
5. При переносе незавершённой работы используй `docs/ai/HANDOFF_PROTOCOL.md` и одно поле `NEXT EXACT ACTION`.

Доступный repo-local skill `.qwen/skills/karpathy-guidelines/SKILL.md` применяй, когда он совместим с задачей: минимальный diff, явные предположения и проверка результата. Реальные модели, квоты и runtime-возможности определяются средой, а не этим файлом.

При capability gap сначала зафиксируй: что требуется, почему недостаточно текущих средств, тип средства, существующую альтернативу, обязательность и ожидаемую пользу. Ничего не устанавливай без разрешения владельца.
