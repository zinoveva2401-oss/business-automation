# QWEN.md

- Статус: модельно-специфичный адаптер Qwen Code
- Проект: «Розница в цифрах»
- Репозиторий: `business-automation`

## Порядок работы

1. Сначала прочитай `AGENTS.md` как единый контракт для всех AI-исполнителей.
2. Если существует `docs/ai/handoffs/ACTIVE_HANDOFF.md`, продолжи с указанного там следующего действия.
3. Используй `docs/ai/PROJECT_MAP.md` для минимальной навигации по репозиторию.
4. Сверь доступные средства с `docs/ai/AI_CAPABILITIES.md`.
5. Для передачи незавершённой задачи следуй `docs/ai/HANDOFF_PROTOCOL.md`.

## Специфика Qwen Code

- Qwen Code работает как внешний технический исполнитель; доступность модели и квота определяются текущей средой, а не репозиторием.
- Бесплатная квота может быть ограничена: при риске остановки заранее подготовь компактный handoff.
- Доступный репозиторный навык: `.qwen/skills/karpathy-guidelines/SKILL.md`. Используй его, когда он соответствует задаче.
- Не считай отсутствие Qwen-специфичного инструмента запретом на работу: сначала проверь существующие репозиторные возможности и доступные средства среды.

## При ограничении квоты

Не начинай объёмный следующий этап, если оставшейся квоты может не хватить на проверку. Сначала зафиксируй изменённые файлы, выполненные проверки, оставшуюся работу и одно следующее точное действие по общему handoff-протоколу.

## Источники проекта

Достоверные источники и их приоритет определены в `AGENTS.md` и `docs/ai/PROJECT_MAP.md`. Для сайта используй указанный там `docs/site/SITE_SOURCE_OF_TRUTH_v1.1.md`; не переноси сюда его продуктовые, контентные, визуальные или технические правила.

Этот файл не дублирует общие запреты, правила Git, границы ролей, форматы `CAPABILITY GAP` и `SYSTEM IMPROVEMENT SUGGESTION`: они действуют по `AGENTS.md`.
