## A. Готовая статья → сайт — PASS

Route: live source check → target renderer/content → editorial presentation → frontend → SEO/AEO/schema → browser/console/network → responsive/A11Y/content/link QA → Red Team for significant public material → consolidated fix → regression.

Automatic roles/tools: content implementation, editorial/UI/UX as needed, frontend, `astro-seo`, `playwright`, `design-review` when visual judgment is needed, `screenshot`, `security-best-practices` only by risk.

Owner is not asked to perform mobile, alt, SEO, links or browser QA. Authorial meaning is preserved.

## B. New landing/product page — PASS

Route: business goal and live brand/product/site check → research/reference → distinct internal options → product/UX/art direction → frontend/responsive/motion by meaning → SEO/AEO → A11Y → performance → security baseline → browser/visual QA → Red Team → consolidated fix → regression.

Automatic roles/tools: business-aware lead, product analyst, creative/art/UI/UX, frontend, `frontend-design`, `astro-seo`, `playwright`, `design-review`, `kill-ai-slop`, `screenshot`, `security-best-practices`, independent `multi_agent_v1` reviewer where useful.

No owner micro-approval is required for grid, type, spacing, responsive or interaction. Public publication remains an explicit release gate.

## C. Technical defect — PASS

Route: reproduce defect → read target and direct dependency → focused patch → focused test/build/browser check → regression of dependent path.

Automatic roles/tools: technical lead/frontend/browser QA; `playwright` and `security-best-practices` only if the defect risk requires them. Creative research, alternative visual directions and motion are not activated without a demonstrated need.

## D. Visually complex editorial/public asset — PASS

Route: business/content goal → live brand/reference check → art/editorial/typography direction → meaningful visual/motion decision → production → real browser render at desktop/laptop/tablet/mobile → visual/responsive/A11Y/SEO/content QA → independent Red Team → consolidated fix → regression.

Automatic roles/tools: creative/art/editorial/UI/UX, frontend/creative technologist, motion by meaning, `frontend-design`, `design-review`, `kill-ai-slop`, `playwright`, `screenshot`, `astro-seo`, A11Y/security/performance checks by risk, independent reviewer via `multi_agent_v1`.

The first render is explicitly a draft; no “ready” handoff is allowed before visual QA and regression evidence.
