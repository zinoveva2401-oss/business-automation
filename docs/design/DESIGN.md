## Visual authority

SYPartners governs composition, hierarchy, density, rhythm, and controlled asymmetry. NOBL contributes only a bounded principle of own semantic visual identity. 11point2 contributes only meaningful motion expressed as `START → ACTION → CHANGE → PAYOFF`. These are bounded references, not a license to copy or merge styles.

The former SITE-BRAND-001 B+A package is a rejected historical negative baseline. It is retained for provenance and BEFORE comparison only.

## Stable implementation rules

- Prefer adult editorial and business-intelligence tone with material evidence and meaningful working context.
- Make the visual event carry the meaning; place information inside or directly beside it.
- Use controlled asymmetry, varied rhythm, and purposeful whitespace instead of repeated equal cards.
- Recompose mobile layouts at 390 rather than only scaling desktop geometry.
- Use `#17130F`, `#262626`, `#F4F5F6`, white, and `#D9562F`; reserve `#2F80ED` / `#173B67` for analytical meaning.
- Treat Trace and result dot as semantic mechanisms, never decoration.
- Use motion only to show meaningful state change and support reduced motion.

## Current Home composition contract

The Site Matrix defines the full Home sequence as header → compact hero → factual evidence → one seven-topic diagnostic strip → articles → tools → current material → founder/about → how DOKRUTI works → compact services → active channels → footer. The first proof scope is deliberately bounded to header context, hero, seven-pain navigation, and the evidence/how-DOKRUTI-works block.

On desktop, the pain navigation is one diagnostic strip across the content width with seven numbered topics, not seven heavy cards or a repeated icon grid. On mobile, use a vertical list or accordion and a shorter hero crop/layout. Do not add unsupported counters, fake proof, autoplay carousel behavior, or equal channel-icon walls.

## Anti-patterns

No generic AI UI, card wall, SaaS dashboard, giant empty hero, template consulting site, Canva/social poster grammar, newspaper imitation, decorative Trace, random gradients, fake metrics, fake cases, fake testimonials, or fake interfaces.

## Route and business preservation

Preserve Astro routes, real texts/articles, seven directions, three frozen services, contacts, SEO/meta/schema/internal links, event hooks, staging noindex, and commercial/legal architecture. Visual work must not change business truth.

## QA gate

Before owner-facing status, compare the exact reference and actual browser render at the same viewport, record `CURRENT → TARGET → AFTER`, test 1440 and 390, inspect console/network/images/overflow and accessibility feasibility, and obtain an independent final visual review. Build or technical PASS does not override visual FAIL.
